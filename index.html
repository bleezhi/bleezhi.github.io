02 / DAILY DRIVER
current daily operating system

macOS Sequoia · OpenCore on AMD

My macOS tinkering centres on an ASUS M1502YA-class laptop with an AMD Ryzen 5 7530U and Radeon integrated graphics. The setup uses OpenCore and a MacBookPro16,2 SMBIOS identity in the hardware report. I'm working through the usual Hackintosh puzzle: ACPI, USB mapping, power management, input, graphics and networking.

macOS Sequoia 15OpenCoreRyzen 5 7530URadeon iGPUMT7902 Wi-Fi

The MT7902 is currently the big networking challenge. It is disabled in the current OpenCore configuration while a dedicated driver is being developed. Kernel extensions run in kernel space, so test builds belong on recoverable setups with a known-good EFI backup.
